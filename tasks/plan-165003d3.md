## Fix 1: Infinite Loop — Package Details Checkboxes

### Root Cause
The Package Details `<Checkbox>` has `pointer-events-none` + controlled `checked` prop + no `onCheckedChange` handler, while the `<Label>` has `htmlFor` pointing to the checkbox `id`. When clicking, the browser redirects the label click to the checkbox, Radix tries to manage internal state, conflicts with the controlled `checked` prop, causing a cascading re-render cycle.

### Fix
Replace `div onClick` + `pointer-events-none` pattern with proper `onCheckedChange` on the Checkbox. Remove the conflicting `pointer-events-none` and label `htmlFor` association.

## Fix 2: drizzle-kit Migration Setup

### Steps
1. Install `drizzle-kit` as dev dependency
2. Create `drizzle.config.ts`
3. Remove old `lib/db/migrate.ts` (replaced by drizzle-kit)
4. Update `package.json` scripts: `db:generate`, `db:migrate`

### drizzle.config.ts
```ts
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  schema: "./lib/db/schema.ts",
  out: "./drizzle",
  dialect: "postgresql",
  dbCredentials: {
    url: process.env.DATABASE_URL!,
  },
});
```

### New npm scripts
- `db:generate` — `drizzle-kit generate`
- `db:migrate` — `drizzle-kit migrate`

### Usage
```bash
pnpm db:generate    # generates migration SQL files in drizzle/
pnpm db:migrate     # applies migrations to Neon
```

Both run under `op run` for 1Password secret resolution.
